# Internationalisation FR / EN — SCPB Survey

## Stack

- `expo-localization` — détection des langues système
- `i18next` + `react-i18next` — catalogues embarqués
- Préférence SecureStore : `scpb_language_preference_v1` = `system` | `fr` | `en`
- Locale affichée résolue séparément (`useLocaleStore`)
- Formats nombres/dates : `src/utils/formatLocale.ts` (`fr-FR` / `en-GB` ; unités kg/ha inchangées)

## Comportement

| Préférence | Affichage |
|------------|-----------|
| `system` (défaut si absente) | Première langue supportée dans `Localization.getLocales()` ; sinon `fr` |
| `fr` / `en` | Forcée ; ignorée si la langue Android change |

- Onboarding : étape langue en premier
- Login : icône globe → sélecteur
- Paramètres : `/(protected)/settings`
- Déconnexion **ne réinitialise pas** la langue
- Hors ligne : catalogues embarqués
- Retour foreground : re-résolution **uniquement** si préférence = `system`

## Questionnaires

- Type `LocalizedString` = `string` (legacy FR) \| `{ fr, en? }`
- Persistance TEXT : plain FR ou JSON `{fr,en}` (`serializeLocalized` / `deserializeLocalized`)
- Affichage collecte via `resolveLocalized` (repli FR — **jamais** d’EN inventé)
- Éditeur question : champs FR + EN (libellé, aide, options)
- Badge complétude EN sur l’éditeur de brouillon
- Publication : avertissement si EN incomplet ; publication FR-only autorisée
- Versions publiées immuables : nouvelle version brouillon pour ajouter de l’EN

## Android — déclaration et limites

- `app.json` → `expo.locales` + `android.locales` pointent vers `locales/android/{fr,en}.json` (nom d’app localisé).
- Plugin `expo-localization` déclaré.
- La préférence **in-app** (SecureStore) est la **source de vérité**.
- Le réglage système « Langues par application » (Android 13+) peut coexister ; **aucune synchronisation bidirectionnelle garantie** avec notre sélecteur sans module natif dédié — l’app ne le prétend pas.
- Vérifier le comportement sur une **APK** (pas seulement Expo Go).

## Couverture UI

Migrés : shell (tabs, headers, switcher), onboarding/login/settings, site-dashboard, planteurs, sync, AdminAvatarMenu, Plus, SurveyRenderer, éditeur questionnaire (chrome + labels FR/EN + complétude).

**Encore souvent en FR hardcodé** : nombreux écrans legacy `sXX-*`, formations/séances détail, lots détail, mapping, remédiation, users admin, messages `Alert` métier — catalogues prêts pour poursuivre.

## Checklist manuelle

1. Téléphone FR / EN / autre → premier lancement (préf `system`)
2. Choix EN onboarding → login → tabs EN
3. Settings → FR → system (indication « langue du téléphone »)
4. Kill app + reopen (préférence conservée)
5. Logout / login (langue conservée)
6. Mode avion (catalogues embarqués)
7. Questionnaire FR-only en UI EN → repli FR + badge / avertissement publication
8. Changer langue UI pendant une collecte → réponses / version / conditions inchangées
9. Foreground après changement langue système (pref = system uniquement)
10. APK : nom d’app + langue in-app (pas Expo Go seul)
